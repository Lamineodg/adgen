Politique de Confidentialité (Privacy Policy)

Application : AdGen Studio • Dernière mise à jour : Novembre 2026

1. Introduction

La présente Politique de Confidentialité décrit la manière dont l'application AdGen Studio traite et protège les informations des utilisateurs lors de l'utilisation de ses services de création publicitaire assistée par intelligence artificielle.

2. Données collectées et finalités

AdGen Studio est conçue selon le principe de minimisation des données :

  • Descriptions textuelles (Prompts) : Lorsque vous utilisez une clé API Gemini personnelle (mode BYOK) ou les services connectés, vos descriptions publicitaires sont transmises de manière chiffrée (HTTPS/TLS) à l'API Google Gemini dans l'unique but de générer le contenu demandé.
  • Stockage local : Vos créations, préférences, crédits quotidiens et votre clé API facultative sont enregistrés exclusivement sur votre appareil. Aucune création n'est stockée ni revendue sur des serveurs tiers.

3. Permissions Android requises

  • android.permission.INTERNET : Nécessaire pour communiquer avec les API de génération IA.
  • android.permission.ACCESS_NETWORK_STATE : Permet de vérifier l'état de la connexion réseau.

4. Partage et revente des données

Nous ne vendons, ne louons et ne partageons aucune donnée personnelle à des tiers à des fins publicitaires. L'application ne contient aucune régie publicitaire tierce.

5. Vos droits (RGPD)

Vous conservez un contrôle total sur vos données : vous pouvez supprimer vos créations à tout moment depuis l'onglet Portfolio ou effacer l'ensemble des données locales depuis les paramètres Android de votre appareil.
